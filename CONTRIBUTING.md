# Contributing

Thank you for your interest in contributing to Pymss Studio!

Pymss Studio is still at an early stage of feature development and under active iteration. We are sorry that we cannot accept external pull requests at the moment — only Collaborators may submit PRs for the time being. Additionally, please note that **breaking changes may occur between versions** during this phase.

However, contributing code is far from the only way to help. There are many other ways to get involved:

- **Report issues and bugs** by opening an issue on GitHub. Clear reproduction steps and environment details help us locate and fix problems faster.
- **Become a co-developer** — if you raise a particularly valuable issue or bug in the issue tracker and the developers fix it, the fix commit will consider crediting you as a co-developer of that change via the `Co-authored-by` trailer.
- **Join discussions** in GitHub Discussions to talk about features, workflows, ideas, or anything related to Pymss Studio. Upvote discussions you would like to bring to the team's attention — we monitor them and consider them when planning development.
- **Share your experience** — write blog posts, tutorials, or how-to guides, and help answer questions from other members of the community.

Once the software is essentially feature-complete and we move into official releases and regular iterations, **we will open pull requests to everyone**. We look forward to that day, and thank you for your patience and support in the meantime.

感谢您对贡献 Pymss Studio 的兴趣！

Pymss Studio 仍处于功能开发的早期阶段，正在积极迭代中。很遗憾，我们目前暂时无法接受外部的拉取请求（Pull Request）——现阶段仅限项目协作者提交 PR。此外，请注意在此开发阶段，**各版本之间可能存在破坏性变更（breaking changes）**。

然而，贡献代码远不是唯一能提供帮助的方式。还有许多其他途径可以参与其中：

- **报告问题和缺陷** —— 在 GitHub 上提交 Issue。清晰的复现步骤和环境信息有助于我们更快地定位和修复问题。
- **成为合作开发者** —— 如果您在 Issue 中提出了一个非常有价值的问题或缺陷，开发者修复后，会在对应的 commit 中考虑通过 `Co-authored-by` 将您署名为该次变更的合作开发者。
- **参与讨论** —— 加入 GitHub Discussions，畅谈功能、工作流、想法或任何与 Pymss Studio 相关的话题。为您希望团队关注的话题点赞，我们会关注这些讨论并在规划开发时加以考虑。
- **分享您的经验** —— 撰写博客文章、教程或操作指南，并帮助回答社区其他成员提出的问题。

一旦软件功能基本完善，并且我们进入正式发布和常规迭代阶段时，**我们将向所有人开放拉取请求的提交**。我们期待那一天的到来，同时也感谢您在此期间的耐心与支持。
